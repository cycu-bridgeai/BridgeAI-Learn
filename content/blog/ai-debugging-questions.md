「我的程式跑不對，怎麼辦？」

這句話很真實，但 AI 還不知道你寫了什麼、輸入了什麼，也不知道你期待看到什麼。把這三件事補上，對話才有辦法往前走。下面用一個 C 程式的例子，示範怎麼問第一句、收到回覆後怎麼追問，以及最後怎麼確認自己真的修好了。

## 第一輪：把看到的現象說清楚

假設題目要用身高和體重算 BMI，範例輸入是 `168, 62.5`，預期輸出 `22.14`。你用這一行讀資料：

```c
int n = scanf("%d %lf", &h, &w);
```

把 `h` 和 `w` 先設為 0，印出 `n`、`h`、`w` 後，實際看到的是 `n = 1`、`h = 168`、`w = 0.000000`。這些數字比「答案錯了」更有用。你可以在 BridgeAI 的 **AI 問答**這樣問：

::prompt-card
我在寫 C 的 BMI 題。輸入 `168, 62.5`，預期 BMI 是 `22.14`。我用 `int n = scanf("%d %lf", &h, &w);` 讀資料，`h` 和 `w` 原本都設成 0；印出來是 `n = 1`、`h = 168`、`w = 0.000000`。請先幫我判斷讀入卡在哪一步，說明你怎麼從這些數字看出來，先不要給我整份完成的程式。
::

這段提問同時交代了**程式的關鍵一行、你輸入的資料、預期結果、實際結果**。AI 如果只給一個修改建議，你也有證據可以問它「為什麼」。完整程式與實測結果在[逗點讓 scanf 讀不到？](/cs/scanf-comma-input)；這裡先專注練習問答。

## 第二輪：追問「為什麼」，再自己改一行

第一輪已知 `n = 1`，表示 `scanf` 只成功讀入一個值。下一句可以把問題縮小：

::prompt-card
`n = 1` 代表第一個值讀到了。請帶我對照輸入 `168, 62.5` 和格式字串 `"%d %lf"`：讀完 `168` 之後，下一個碰到的是什麼字元？為什麼 `%lf` 沒讀到？請只提示我該檢查格式字串的哪一段。
::

現在你有一個可以自己試的方向：格式字串裡只有空白，輸入裡卻有逗點。把那一行改成：

```c
int n = scanf("%d ,%lf", &h, &w);
```

**存檔、重新編譯、用同一筆輸入再跑一次。** 在原本的 BMI 程式中，這次輸入 `168, 62.5`，就能得到 `22.14`。這個結果是程式實際執行的驗證，不是因為 AI 說「應該可以」就算完成。

## 第三輪：換一筆輸入，看修正的邊界

再試 `168 62.5`（中間只有空白）。這次它讀不對，因為你剛剛改的格式字串**要求輸入裡有逗點**。你可以接著問：

::prompt-card
我改用 `"%d ,%lf"` 後，輸入 `168, 62.5` 可以得到 `22.14`；改成 `168 62.5` 卻不行。請解釋逗點在格式字串中的作用，並幫我分清楚「題目要求逗點輸入」和「我想同時接受兩種輸入」是不同需求。
::

這種追問把**新結果**帶回同一段對話。你不是從頭再問「為什麼壞了」，而是讓 AI 根據剛剛的修改繼續分析。題目只要求哪種輸入，就先用那種輸入驗證；別把範例以外的需求當成這一題一定要解的問題。

## 如果卡住的是環境，也用同樣方式問

程式還沒跑起來時，先貼你打的指令和終端機顯示的結果。例如 VS Code 的 PowerShell 找不到 `gcc`，可以這樣問：

::prompt-card
我在 Windows 的 VS Code PowerShell 輸入 `gcc --version`，終端機說找不到 `gcc`。我目前還沒有編譯任何 `.c` 檔。請先幫我分辨「GCC 沒安裝」和「PATH 找不到 GCC」要怎麼檢查；一次給我一個要做的檢查和我該回報的結果，先不要叫我重裝所有工具。
::

照著建議做完第一個檢查，再回覆**你實際看到的結果**，例如 `gcc.exe` 在不在、`where.exe gcc` 有沒有列出路徑。不要把 AI 猜測的結果當成你的電腦狀態。指令怎麼打、在哪裡打，可以對照[Windows C 環境卡住時怎麼查](/cs/c-setup-troubleshooting)。

## 每一輪都留下一個可驗證的下一步

下次卡關，可以照這四項提供資訊：

1. **我想做到什麼？** 題目要求與預期輸出。
2. **我實際做了什麼？** 關鍵程式碼或終端機指令，以及輸入資料。
3. **我看到了什麼？** 完整錯誤訊息，或實際輸出。
4. **我希望先檢查哪一件事？** 請 AI 說明原因、給一個檢查步驟，或檢查你的推論。

收到回答後，先做它建議的那一步，再把**修改後的程式或指令，以及新輸出**貼回同一段對話。最後以編譯器、執行結果和題目的測試結果為準。這樣一輪一輪縮小問題，你也能說清楚自己究竟改對了哪裡。

如果你在 **練習場選題作答**，或在**課程作業**解題，提交後結果沒有通過，可能會看到「申請 AI 助教引導」按鈕。它會根據那次提交的程式和判題結果提供分層提示；這與上面示範的自由提問是不同的使用方式。按鈕需要該次提交已儲存、功能已開啟；[三層提示怎麼用](/blog/ai-guidance)以一題課程作業示範這個流程。
