> **PY05_計算BMI(cm)**
>
> 輸入身高h(cm)、體重(kg)。請輸出相對應的BMI？ (Hint: BMI 計算公式是以體重(公斤) 除以身高(公尺)的平方)
>
> 請使用.2f，輸出到小數點後第2位。
>
> 範例輸入：`168, 62.5`　範例輸出：`22.14`

範例輸入的兩個數字中間夾了一個**逗點**，可是上課時讀兩個數字都是用空白隔開：`scanf("%d %lf", &h, &w);`。照抄會怎樣？我們把 scanf 讀到的東西印出來看（`w` 先設成 0，才看得出有沒有被填）：

```c
#include <stdio.h>

int main(void) {
    int h = 0;
    double w = 0;
    int n = scanf("%d %lf", &h, &w);
    printf("scanf 讀到 %d 個值：h = %d, w = %f\n", n, h, w);
    return 0;
}
```

**輸入** `168, 62.5` → **輸出** `scanf 讀到 1 個值：h = 168, w = 0.000000`

身高讀到了，體重沒有。

## 為什麼？scanf 拿著「樣板」一格一格對

雙引號裡的東西就是樣板，scanf 從你輸入的第一個字開始往右對：`%d` 讀整數、`%lf` 讀小數（`double`）、樣板裡的**空白**會吃掉輸入裡的空白（一個都沒有也沒關係），而**逗點這類符號**，輸入裡那個位置就一定要剛好是它。只要有一格對不上，scanf 就停下來，後面的變數都不會被填。

下面第二行是課堂寫法，第三行是改好的寫法（`_` 代表空白，`^` 是卡住的地方）：

```text
              1 6 8 , _ 6 2 . 5
"%d %lf"      [%d-] ^
"%d ,%lf"     [%d-] , [--%lf--]
```

課堂寫法的 `%d` 讀走 `168` 之後，`%lf` 想讀數字卻看到逗點，就卡住了。前面印出的「讀到 1 個值」就是 scanf 在說：我只讀成功 1 個。改好的寫法在樣板裡放了逗點，剛好對上輸入的逗點，`%lf` 再把 `62.5` 讀走。

三種樣板、五種輸入，我們全部實際跑過（✅ 兩個值都讀到，❌ 只讀到身高）：

| 樣板 | `168, 62.5` | `168,62.5` | `168 ,62.5` | `168 , 62.5` | `168 62.5` |
| --- | --- | --- | --- | --- | --- |
| `"%d %lf"`（課堂寫法） | ❌ | ❌ | ❌ | ❌ | ✅ |
| `"%d, %lf"` | ✅ | ✅ | ❌ | ❌ | ❌ |
| `"%d ,%lf"` | ✅ | ✅ | ✅ | ✅ | ❌ |

注意最右欄：只用空白隔開的輸入，改好的寫法反而讀不到。沒有萬用寫法，**先看範例輸入長什麼樣子，再決定樣板**。

## 解法

```c
#include <stdio.h>

int main(void) {
    int h;
    double w;
    scanf("%d ,%lf", &h, &w);
    double m = h / 100.0;
    printf("%.2f\n", w / (m * m));
    return 0;
}
```

用課程建議的指令編譯：`gcc -Wall -Wextra -std=c11 bmi.c -o bmi`

**輸入** `168, 62.5` → **輸出** `22.14`，跟範例輸出一樣。

逗點前面那個空白是保險，有人輸入 `168 ,62.5`（逗點前多一個空白）也讀得進來；逗點後面不用加空白，因為從表格可以看到，`%lf` 會自己跳過數字前面的空白。

## 另外兩個常見陷阱

**身高是整數，除法會把小數吃掉。** 把解法裡的 `printf` 那行寫成：

```c
printf("%.2f\n", w / ((h / 100) * (h / 100)));
```

**輸入** `168, 62.5` → **輸出** `62.50`。因為 `h` 和 `100` 都是整數，C 會做**整數除法**，`168 / 100` 得到 `1`，小數直接被丟掉。改成 `h / 100.0`，讓其中一邊是小數就好。

**`double` 用 `%f` 讀。** 把一開始那支程式的 scanf 換成：

```c
int n = scanf("%d ,%f", &h, &w);
```

編譯時編譯器其實已經在提醒你：

```text
warning: format ‘%f’ expects argument of type ‘float *’, but argument 3 has type ‘double *’ [-Wformat=]
```

不理它直接執行，**輸入** `168, 62.5` → **輸出** `scanf 讀到 2 個值：h = 168, w = 0.000000`。scanf 說讀到 2 個值，`w` 卻不對。**scanf 讀 `double` 一定用 `%lf`。**

## 自我檢查

- [ ] 數字之間隔的是空白、逗點，還是別的符號？樣板照著寫，符號前面加個空白當保險。
- [ ] 變數是 `double`，scanf 就用 `%lf`。
- [ ] 除法的兩邊，至少有一邊是小數（例如 `100.0`）。
- [ ] 不確定有沒有讀到？把 scanf 的回傳值印出來，看是不是等於變數個數。

**小練習**：輸入變成 `62.5; 168`（體重在前、用分號隔開），scanf 要怎麼寫？先想一下再看答案。

答案：`scanf("%lf ;%d", &w, &h);`，套進解法的程式，**輸入** `62.5; 168` → **輸出** `22.14`。
